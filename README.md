# Sistema de Detección Temprana y Alerta de Deserción Escolar (Caso 7)
## Descripción
La deserción en educación media se aborda actualmente de forma reactiva debido al uso de registros físicos o planillas desarticuladas que impiden detectar a tiempo las inasistencias y reprobaciones.
Esta falta de herramientas integradas frena la identificación temprana del riesgo académico y dificulta tanto la derivación oportuna de los estudiantes a equipos psicosociales como el resguardo de la privacidad de sus datos personales y socioeconómicos.
